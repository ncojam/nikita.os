# Файловая система

Пользователь видит одно дерево (`/home/nikita/...`), собранное из четырёх источников:

| Слой | Где живёт | Кто меняет | Видят |
|---|---|---|---|
| Канон `/fs` | `./fs` (`NOS_FS`), read-only | только автор руками / деплоем | все |
| Общие папки `/ufs` | `NOS_DATA/ufs` | вошедшие пользователи (`userfs.py`) | все |
| Записи `.запись` | `ufs/.meta/posts.json` (файлов на диске нет) | авторы (`posts.py`) | все |
| Личный слой | IndexedDB браузера | сам посетитель (VFS) | только он |
| Зеркало GitHub | GitHub API | — | все (грузит браузер) |

## Сшивка на сервере

`api_ls`: сначала канон (он главнее при коллизии имён, помечается без флагов), потом `/ufs` (`"ufs": true`), потом записи (`"post": true`).
`serve_fs`: файл из канона → файл из `/ufs` → JSON записи по виртуальному пути.
Проверки «есть ли папка / занято ли имя» — `unified_dir_exists`, `unified_name_taken`.

## Общие папки (`userfs.py`)

- ≤ `NOS_UFS_MAX_FOLDERS` папок на пользователя, ≤ `NOS_UFS_MAX_SUB` пользовательских подпапок в папке, глубина ≤ `NOS_UFS_MAX_DEPTH`.
- Удаляет только автор, удаление уносит всё внутри: `Folders.delete → posts.purge_dir → chat.drop_comments`.
- Клиент: `remote/userfolders.js` (`createServerFolder`, `deleteServerFolder`).

## Записи

Виртуальный файл `Имя.запись` в любой общей папке; содержимое — JSON `Posts.public()`. Подробно — [social.md](social.md).
В **локальной** папке запись становится черновиком: `{draft: true, ...}` пишется через VFS, картинка — data-URL внутри файла.

## Личный слой: VFS + Service Worker

```
приложение ── fetch /api/ls, /fs/... ──▶ sw.js ──▶ сервер
                                         │  └─ overlay-core.js: наложить state на ответ
приложение ── VFS.move/remove/rename/mkdir/upload/writeFile ──▶ IndexedDB ──▶ SW перечитывает слой
```

- `overlay-core.js` — обычный (не module) скрипт: его грузят и `index.html`, и `sw.js` (`importScripts`).
- Состояние: `state.hidden[vpath]` — скрытые серверные пути; `state.nodes[vpath]` — `dir` / `file` (blob) / `link` (так выглядит перемещённый серверный файл).
- Пока посетитель ничего не менял — запросы идут на сервер как есть.
- После изменения страница ждёт подтверждения от SW (через `MessagePort`), иначе следующий `/api/ls` пришёл бы по-старому.
- Перетаскивание и удаление иконок — `ui/fs-dnd.js`. Общие (`ufs`) объекты локально не двигаются: `canTouch()`.

## Зеркала GitHub (`remote/github.js`)

Файл `github.mount` в папке (`owner/repo`, ссылка или JSON `{repo, branch, path}`) — проводник показывает вместо папки дерево репозитория. Всё делает браузер через GitHub API, сервер не участвует. `openPath` тоже умеет искать пути внутри зеркал.
