# DAWN — пастельная DAW

Код — `public/js/apps/dawn/`. Только клиент: сервер отдаёт файлы и ничего не знает о DAWN. Рассчитан на компьютер.

## Главная идея: модуль = окно ОС

У DAWN нет «главного окна с вкладками». Каждый модуль — отдельное окно оконного менеджера: их можно таскать, раскладывать сеткой, сворачивать. Все окна смотрят на один движок, поэтому если закрыть окно, звук и данные не пропадут.

| Окно | Модуль | Ключ |
|---|---|---|
| Транспорт (хаб) | ▶ ■, позиция, BPM, паттерн, Master/Swing, осциллограф, кнопки модулей, сохранение | `transport` |
| Стойка каналов | каналы, шаги паттерна, vol/pan, mute (ПКМ — соло), добавление каналов | `rack` |
| Пиано ролл | ноты канала в текущем паттерне + полоса velocity | `piano` |
| Инструмент | панель 3XOSC или сэмплера + мини-клавиатура | `inst:<id канала>` |
| Сэмплы | дерево ФС (аудиофайлы) + встроенные ударные | `browser` |

Закрыли транспорт — закрылся весь проект: остальные окна закрываются, а несохранённое уходит в черновик.

## Файлы

| Файл | Что |
|---|---|
| `engine.js` | `Engine`: AudioContext, модель проекта, планировщик, инструменты (3XOSC, сэмплер), встроенные ударные, кэш сэмплов, события |
| `index.js` | `Dawn` — хаб окон (`open/close`, общие клавиши, раскладка), сохранение/открытие `.dawn`, черновик; `openDawn(path)` |
| `windows.js` | модули: транспорт, стойка, инструмент, браузер сэмплов (`MODULES`) |
| `pianoroll.js` | пиано ролл (canvas) |
| `ui.js` | крутилка `knob`, LED, кнопки, корпус окна, имена нот |

## Модель проекта (`.dawn` — JSON)

```js
{ v: 1, name, bpm, swing, master,
  patterns: [{ id, name, color, bars? }],
  channels: [{ id, type: "osc3" | "sampler", name, color, vol, pan, mute, solo, params }],
  notes: { [patternId]: { [channelId]: [{ s, l, n, v }] } },   // s, l — в шагах (1/16), n — MIDI, v — 0..1
  cur: patternId,
  layout: { [ключ окна]: [left, top, width, height, открыто] } }
```

Шаги стойки и пиано ролл — **одни и те же ноты**, как в FL: шаг = нота длиной 1 шаг. Длина паттерна — по последней ноте или по `bars`, всегда кратна такту.

## Движок

- **Планировщик** с упреждением: таймер раз в 25 мс досылает в Web Audio ноты на ближайшие 120 мс с точным временем `ctx.currentTime`. Сейчас крутится текущий паттерн по кругу (плейлист появится на этапе 2).
- **Цепочка:** голос → полоса канала (gain → pan) → master → мягкий лимитер → analyser → выход. Микшер на этапе 2 встанет между полосой и мастером.
- **3XOSC:** 3 осциллятора (sine / triangle / saw / square / noise, Crs, Fine, Pan, Vol) → lowpass-фильтр (Cut, Res) → ADSR.
- **Сэмплер:** сэмпл из ФС (`/fs/...`) или встроенный (`builtin:kick` и т. п. — рендерится в `OfflineAudioContext`, файлов не нужно); Root, Tune, Start, Att, Rel, One-shot, Reverse.
- **События** `Engine.on(...)`: `change` — изменилась модель; `{ param: true }` означает правку крутилки, на неё окна **не перестраиваются** (иначе крутилка пропадёт из-под мыши). Ещё есть `play`, `stop`, `pattern`.
- Крутилки описаны в `SPECS` (min/max/def/кривая) и имеют адрес `ch.<id>.<param>` — на этапе 3 по нему повесим огибающие.

## Сохранение

- 💾 / Ctrl+S → `/home/nikita/Desktop/<имя>.dawn` через `VFS.writeFile`: это файл в **локальном слое** посетителя, видит его только он. Открывается двойным кликом.
- Сэмплы хранятся путями (`/home/...` или `builtin:...`), не внутри файла.
- Черновик: при каждом изменении проект пишется в `localStorage` (`dawn.autosave`). При следующем открытии без файла DAWN предложит его восстановить.

## Клавиши (в любом окне DAWN)

Пробел — пуск/стоп, Ctrl+S — сохранить, Ctrl+Shift+S — сохранить как.
