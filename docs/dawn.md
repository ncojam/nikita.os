# DAWN — пастельная DAW

Код — `public/js/apps/dawn/`. Только клиент: сервер отдаёт файлы и ничего не знает о DAWN. Рассчитан на компьютер.

## Главная идея: модуль = окно ОС

У DAWN нет «главного окна с вкладками». Каждый модуль — отдельное окно оконного менеджера: их можно таскать, раскладывать сеткой, сворачивать. Все окна смотрят на один движок, поэтому если закрыть окно, звук и данные не пропадут.

| Окно | Модуль | Ключ |
|---|---|---|
| Транспорт (хаб) | ▶ ■, PAT/SONG, позиция, BPM, паттерны, Master/Swing, осциллограф, модули, сохранение, ⬇ WAV, тема | `transport` |
| Стойка каналов | каналы, шаги паттерна, размер (7/4, 11/4…), дробная длина, vol/pan, mute (ПКМ — соло), номер инсерта | `rack` |
| Пиано ролл | ноты канала + velocity; строй (EDO), лад, тоника, привязка к ладу | `piano` |
| Плейлист | общий таймлайн: клипы паттернов на дорожках | `playlist` |
| Микшер | Master + инсерты: громкость, пан, индикаторы, до 4 эффектов на инсерт | `mixer` |
| Инструмент | панель 3XOSC или сэмплера, маршрут в микшер, мини-клавиатура | `inst:<id канала>` |
| Сэмплы | дерево ФС (аудиофайлы) + встроенные ударные | `browser` |
| Модуляция | ручки, огибающие, LFO и их проводки к параметрам DAWN и ОС | `mods` |
| Проект как текст | проект в `dawn/2`: скопировать для нейросети (инструкция + JSON Schema + проект) / загрузить из текста | `ai` |

Закрыли транспорт — закрылся весь проект: остальные окна закрываются, а несохранённое уходит в черновик.

## Модель и формат

Файл `.dawn` — JSON в формате **`dawn/2`**, его описание — [dawn-format.md](dawn-format.md). Время в долях, высоты именами нот, id короткие — такой файл можно отдать нейросети и загрузить её ответ обратно (окно 🤖).

Внутри приложения модель почти такая же, только ноты — объекты `{ s, l, n, v }` с числовой высотой `n` (номер ступени строя канала) и `notes` лежат прямо в паттерне. Длина паттерна — `len` или по нотам (целыми тактами размера `sig`).

## Движок

- **Тик** планировщика — 1/16 (0.25 доли). Таймер раз в 25 мс досылает в Web Audio ноты на ближайшие 120 мс. Темп можно менять на ходу: время следующего тика копится, а не считается от старта.
- **PAT** — по кругу текущий паттерн; **SONG** — плейлист: в каждом тике берутся клипы, накрывающие позицию, и ноты паттерна по модулю его длины. Песня тоже идёт по кругу; откуда играть — треугольник на линейке плейлиста.
- **Граф:** голос → полоса канала (gain → pan) → вход инсерта → эффекты (включённые, по порядку) → громкость/пан инсерта → индикатор → Master (инсерт 0) → предохранитель → выход. `buildGraph(ctx, project)` одна для `AudioContext` и `OfflineAudioContext`, поэтому WAV звучит ровно как в DAWN.
- **Строи:** у канала свой `edo`. Частота `8.1758 · 2^(n/edo)`, у сэмплера — `playbackRate = 2^(n/edo − root/12)`. При смене строя ноты переносятся на ближайшие по высоте ступени.
- **Экспорт WAV:** песня из плейлиста (или текущий паттерн, если плейлист пуст) плюс 3 с хвоста, 44.1 кГц / 16 бит.
- **События** `Engine.on(...)`: `change` (`{ param: true }` — правка крутилки, окна не перестраиваются), `play`, `stop`, `pattern`, `mode`, `theme`.

## Темы

☀/🌙 в транспорте переключает тему. Выбор хранится у посетителя (`localStorage` `dawn.theme`), а не в проекте.
- **Тёмная** — неон на тёмном.
- **Светлая** — каждое окно, включая заголовок, залито пастелью своего модуля: транспорт — розовый, стойка — лавандовый, пиано ролл — голубой, плейлист — лимонный, микшер — персиковый, сэмплы — мятный, инструмент — цветом канала.

Цвета canvas берутся из `pal()` в `ui.js`. Тема включается атрибутом `data-dawn-theme` на `<html>`.

Правую кнопку DAWN забирает себе (удаление нот и клипов): `shell()` гасит `contextmenu`, а меню ОС не открывается, если событие уже обработано.

## Модуляция и проводки

- **Источник** (`project.mods`): ручка (`knob`, 0..1), огибающая (`env`: точки во времени, едет вместе с песней/паттерном, повтор) или LFO (`lfo`: период как у дилея, форма).
- **Провод:** `{ to: адрес, amt: −1..1 }`. Цель = база + amt · (v − центр) · (max − min), где центр 0.5 у LFO и 0 у остальных. Провода в одну цель складываются. Сохранённые значения не меняются: сняли провод — значение вернулось.
- **Адреса:** `ch.<канал>.vol|pan|<параметр>|osc1.o_vol|op2.ratio|m21`, `mix.<инсерт>.vol|pan|<слот>.<параметр>`, `os.<id>` — параметры самой ОС.
- **Как подключить:** тянуть провод из гнезда ● на любую крутилку (у крутилок есть `data-path`) или выбрать цель в списке «＋ цель». «🔌 Провода» рисует кабели поверх всех окон. Модулируемая крутилка показывает тонкую дугу текущего значения и значок ∿.
- **Применение:** `Mod.tick` 30 раз в секунду считает `computeOver`. Цели DAWN уходят в `G.applyOver`: громкость, пан, фильтр звучащих голосов и эффекты меняются сразу, остальное — с ближайших нот. Цели ОС идут через `core/params.js`. При рендере WAV `OfflineAudioContext` приостанавливается на каждом тике (`suspend`), поэтому огибающие и LFO попадают в файл.

### Источники «По ноте» и «Уровень»

- **⚡ По ноте** (`trig`): огибающая Att/Hold/Rel в мс, стартует от каждой ноты выбранного канала (с учётом силы ноты). Провод с минусом на громкость других каналов — сайдчейн. В WAV-рендере шаг модуляции — 1/16, вживую ~30 раз в секунду.
- **📶 Уровень** (`meter`): громкость инсерта микшера как источник (Gain — чувствительность).

### Провода: физика, ветер, снять провод

Провода — верёвки (Verlet, 16 точек): провисают, качаются. Источник **🌬 Ветер** (`wind: { input, strength, gust }`) раскачивает все видимые провода; вход — любой другой источник (бочка «По ноте», LFO…) или постоянный; его собственные провода — как у любого источника. Нажать на кружок конца провода на крутилке — провод снимается и остаётся в руке: бросил на другую цель — переподключил, в пустоту — снят.

### Педали (`pedals[]`)

Эффект вне микшера: `{ id, type, on, in: "ch:<канал>" | "mix:<инсерт>", out: "mix:<инсерт>", …параметры }`. Вход канала берётся до инсерта, инсерта — после фейдера; звук идёт параллельно основному. ⏏ в микшере отсоединяет эффект в педаль, ⏎ — возвращает. Петли запрещены (вход-инсерт ≠ выход, Master как вход нельзя). Параметры — цели проводков `pedal.<id>.<параметр>`. Новые эффекты (и в микшере, и педалями): **ƒ Formula** (`expr` — выражение от x, t, a, b; есть sin, tanh, clip, fold, crush…) и **{} Code** (`code` — тело функции `(x, t, a, b, ch, state, sr) → y`). Оба — AudioWorklet (`loadCodeWorklet` в fx.js), код работает без DOM и сети; ошибка → звук проходит как есть и уведомление.

### Общие проекты на сервере (`dawnstore.py`)

Вошедший через чат сохраняет проект на сервер в любую существующую папку (`POST /api/dawn/save`, файл ложится в /ufs и виден всем): до 10 проектов, ≤ 2 МБ (`NOS_DAWN_MAX_PROJECTS`, `NOS_DAWN_MAX_BYTES`), перезаписать/удалить — только свой (`/api/dawn/delete`, `/api/dawn/mine`). Не вошедший сохраняет в браузер и видит плашку-памятку про регистрацию.

Счётчик посещений DAWN — `POST /api/visit {app, id, hit}` → `data/visits.json` (хранится хэш id посетителя); в доке справа «👁 уникальные · открытия».

### Любые регуляторы ОС и окна (`core/uiparams.js`)

Провод можно бросить на любой ползунок/числовое поле/крутилку в любом окне ОС — адрес `ui.<ключ окна>#<номер>`; регулятор двигается так, будто его крутит человек, снял провод — вернулся. Бросил на заголовок окна — `win.<ключ>.shake`. Эффекты окон: `win.<ключ|*>.shake | tilt | zoom | fade | jump`.

Клик по карточке источника показывает все его провода; если цель в свёрнутом или закрытом окне — рисуется табличка, клик по ней открывает окно.

### Параметры ОС (`core/params.js`)

Общий реестр: `Params.addProvider({ prefix, list(), resolve(addr) → { spec, base(), apply(v), restore() } })`. Любой модуль может выставить свои ручки. ОС выставляет CSS-переменные из **`fs/etc/params.json`**: оттенок и насыщенность окон, скругление, размытие стекла, размер заголовков, яркость и оттенок обоев. Чтобы добавить новую, допиши строку в JSON и используй `var(--…)` в CSS — код менять не нужно.

## Инструменты

- **3XOSC:** под огибающей нарисована её форма (A-D-S-R), обновляется, пока крутишь.
- **Grapefruit — форма волны и огибающие:** у оператора Skew (перекос фазы), Fold (складывание, живой шейпер) и Crush (ступеньки) с картинкой волны; огибающая «Fold» ведёт складывание внутри ноты. A~ D~ R~ — закругление участков ADSR (изинг вверх/вниз; кривая `ease` в `instruments.js`, работает и у 3XOSC). ⇔ у оператора — его огибающая пропорциональна длине ноты (настроена под ноту в 1 долю). Skew/Fold/Crush — цели модуляции (`ch.X.opN.wsk|wfold|wcrush`); синт читает их в начале ноты, так что LFO делает каждую ноту другой, а движение внутри ноты — огибающими.
- **Риддим-пресеты** (по прослушиваниям cojam): основа — семейство **Metal Crush** (синус октавой ниже + немного квадрата, crush с закрытым Tone, огибающая «по ноте» раскрывает Tone — металл нарастает внутри ноты): 3XOSC Metal Rise / Creak / Snap / Yoi / Deep / Grind Fifth, Grapefruit Metal Crush FM / Metal Creak FM / Extreme Creak FM / Metal Scream FM / Iron Yoi FM / Iron Yoi Up FM (высота уходит вверх после отпускания) / Creak Glide FM. Пресеты Grapefruit могут нести модуляцию (`GF_MODS` в presets.js). Laser, Tearout, Howl, Screech Rise, Shred оставлены как пресеты, но в генерилки не берутся.
- **Grapefruit** (в духе Sytrus): справа матрица «кто кого» 4×4 (столбец — источник, строка — цель; снизу вверх — обратная связь через задержку в блок) и строка OUT; у оператора волны sine/triangle/saw/square/organ/pulse/hollow/custom (8 гармоник рисуются), pan; нарисованные огибающие громкости, панорамы и высоты (`op.env.vol|pan|pitch = { on, sus, pts: [[сек, 0..1]], range }`, Shift-клик — точка удержания). Было: FM, 4 оператора (волна, ratio, fine, level, out, своя ADSR с картинкой), матрица модуляции «кто → кого» (только старший → младшему, чтобы в графе не было петель), фильтр, пресеты E-Piano / Bell / FM Bass / Glass Pad / Pluck.
- **Unison** у 3XOSC: `uni` голосов на каждый осциллятор, `udet` — разброс в центах, `uspr` — ширина в стерео.
- **Пресеты** «✨» в шапке инструмента ставят и звук, и эффекты на инсерт канала (если инсерт общий — канал пересаживается на свободный).
- **Свои сэмплы:** кидай файлы в `~/Samples` (или перетащи на рабочий стол) — они появятся в браузере сэмплов.
- **Poly:** максимум голосов у любого инструмента. Лишний старый голос крадётся (быстрый спад); 1 — моно.
- **Клон канала** ⧉ в стойке: копия инструмента или сэмпла со всеми настройками, сразу под оригиналом.

## Библиотека и быстрые паттерны

Разделы по жанрам (свёртываются кликом по заголовку). Новые встроенные ударные: Kick punch, 808, Snare fat, Rim, Snap, Shaker, Crash, Ride, Cowbell, Conga, Metal hit, Impact, Reverse crash (`BUILTIN` в instruments.js, роли в `ROLES` library.js).

Недостающие ударные каналы создаются сами.

## Док DAWN и живой фон

Окна DAWN живут на своей панели сверху (`.dw-dock`: ▶/■, позиция, задачи окон), а не на панели задач ОС. WM учитывает её через класс `.wm-reserve-top` и опцию `WM.open({ taskList })`: окна не перетаскиваются под панель, а когда она появляется (или меняется размер экрана) — `WM.fitReserved()` сдвигает окна ниже неё и подгоняет развёрнутые.

Качество подстраивается само (`LEVELS` в `ui/glow.js`, 6 ступеней): по интервалам кадров (3 с) — ступень ниже: меньше разрешение холста и кадров → стекло окон без размытия (`html.fx-lite`) → меньше светяшек → непрозрачные окна без теней (`html.fx-solid`) → без тряски окон, переходов и анимаций (`html.fx-calm`); на последней — один раз предлагает выключить фон. Ступень запоминается для устройства (`bg.quality`), в Настройках — «Качество: Авто / вручную». Телефоны стартуют экономно, при «уменьшить движение» фон выключен.

Каналы с цветом вспышки ✦ (по умолчанию бочка — розовый, малый/клэп — бирюзовый) шлют событие `nos-pulse`, и светяшки фона ОС (`ui/glow.js`) вспыхивают в такт. Настройки фона — «Настройки → Живой фон»; параметры `bg.*` (оттенок, скорость, яркость, размер, сила вспышек, количество) доступны проводкам модуляции.

## ✨ Магия (`magic.js`)

Окно с умными функциями (кнопка «✨ Магия» в транспорте). `analyze()` читает паттерн: размер, длину, темп, лад (у канала или по нотам), бас (самый долгий низкий синт), ударные по ролям, стиль (темп + где малый/хлопок + частота бочки).
- **Достроить композицию** (`compose`): интро → (нарастание → дроп → брейк) × число дропов → аутро. Основа (`basePattern`): текущий паттерн, весь трек (самый «полный» паттерн плейлиста, служебные «✨ …» не в счёт) или участок от маркера ▼ на N тактов. Шесть ползунков (`LEVELS`, 0..1):
  - **Драматичность** — саб-бас в поздних дропах, «удары», медленные вубы, последний дроп длиннее;
  - **Переделывание** — доля вариаций и сила изменения синтов;
  - **Крутость** — металл и модуляция у новых синтов;
  - **Мелодичность** — арпеджио по аккордам пэда («Arp ✨»), длиннее брейки;
  - **Саспенс** — длина нарастаний (≈ 2–8 тактов), поздний ролл малого, «вдох» без бочки посередине, дрожь окон;
  - **Брейки и дыры** — вероятность брейков и «дырявых» паттернов (в полутактах выпадают ударные и вуб).
  **Интро** (`INTROS`): пэд + хэты, рифф дропа за фильтром (огибающая «✨ Intro filter»), арпеджио, атмосфера, только грув, тёмный саб; **нарастания** (`BUILDS`): ролл, ускоряющиеся вуб-чопы, рифф дропа, сирена, стоп-пауза с обратной тарелкой, триоли с томами — выбираются «под синт дропа», случайно или вручную. **Смена синта в дропе:** каждые 4 паттерна (2 — в коротком) звук меняется на другой из семейства риддим-пресетов; сколько звуков (1–3) — от «Переделывания».
  Каждый дроп после первого — со своим синтом: клон вуба «Wub D2 ✨»… с улучшайзером (металл / модуляция / бас / реверс атаки / случайный — по ползункам), с «⇔ под длину ноты». В нарастании перед ним этот синт уже тянет корень (тизер), а огибающая «✨ Build sweep» (одна на песню, видна полосой в плейлисте) открывает фильтры пэда, райзера и тизера и обрывается на дропе. Каждый запуск — новое зерно, результат каждый раз другой. Пресеты: Стандарт, Короткий, Длинный клубный, Жёсткий риддим, Мелодичный, Долгий саспенс (+ свои ⭐).
- **Брейки по треку** (`addBreaks`): весь трек или участок от маркера ▼; плотность 0..1 — клипы с ударными заменяются брейками (ролл, заикание, провал, томы) и «дырами».
- **Ударные по стилю** (`drumsForStyle`): грув из библиотеки, если размер подходит, иначе — по группам 2/3 восьмых; заменяет только ударные.
- **Брейки** (`fillNotes`): ролл, заикание, провал, томы — паттернами или «каждый 4-й клип в плейлисте».
Случайность с зерном: 🎲 — другой вариант.
- **Вубы** (`A.wub` — синт с наибольшим числом нот, низкие в приоритете): удлинённые вубы (на том же синте соседние ноты такта сливаются — «1-2» вместе, весь такт, пары, «3-4» — у новой ноты `x` = во сколько раз она длиннее первой, атака и спад растягиваются так же), металлические вариации (клон «Wub metal ✨» с металлом), **Дроп B драматичнее** — саб-бас «Sub ✨» на 1–2 октавы ниже по корню такта, металл, медленные вубы, брейки каждые 2 паттерна (ролл, заикание по металлу, провал). Галочки «Медленные вубы», «Металлические вариации», «Дроп B драматичнее».

### Вубы (`wubs.js`)

- **⇔ под длину ноты** (`params.fit`, у 3XOSC и Grapefruit): атака ≤ 45% ноты, спад ≤ 35%, релиз ≤ 50% (у Grapefruit — и нарисованные огибающие сжимаются) — частые вубы слышны, длинные звучат с полной атакой.
- **🪄 Улучшить…** (3XOSC): ＋ Металл (квадрат +12 с расстройкой, crush с низким Tone + огибающая «По ноте» на Tone), ＋ Бас (синус −12, полка EQ), ＋ Модуляция (LFO в такт на фильтр и Tone), ⟲ Реверс атаки (нарастание и обрыв), 🎲 Случайный риддим-вуб (случайные волны, атака, фильтр + металл/модуляция с вероятностью).

## ⭐ Свои пресеты (`userlib.js`)

Всё готовое можно сохранить своим (в браузере, localStorage `dawn.user`; ⬇/⬆ в Библиотеке — файл `dawn-presets.json`, чтобы перенести или поделиться):
- **звук** — ⭐ в шапке инструмента: параметры + эффекты инсерта (если он только этого канала) + модуляция канала (адреса относительно канала: `ch.x`, `fx.N.x`). Появляется в «✨ Пресет…» как «★ имя»; 🗑 — удалить;
- **паттерн** — Библиотека → «⭐ Мои» → сохранить ударные / синты / весь: ударные по ролям, синты вместе со звуком (при вставке ищется канал с тем же именем и типом, нет — создаётся);
- **настройки «Магии»** — ⭐ рядом с выбором пресета (есть готовые: Стандарт, Короткий, Длинный клубный, Без пэдов и райзеров).

## Плейлист: выделение и правка

Ctrl + тянуть (или ⬚) — выделить участок (по линейке — все дорожки). ⧉ копировать (Ctrl+C), 📋 вставить у маркера ▼ (Ctrl+V), ⧉→ дублировать (Ctrl+B), ✂ разрезать по краям, ★ сделать паттерны уникальными, 🗑 удалить (Del), Esc — снять. Разрезанный клип играет с середины паттерна: `offset` в файле (`o` в модели). **ПКМ по любой ручке → «Сделать автоматизацию»**: нарастание / спад / вверх-вниз / волна / ступеньки — огибающая ложится ровно на выделенный участок (без выделения — на весь трек); там же «убрать автоматизацию этой ручки».

## Огибающие на плейлисте

Источники «Огибающая» из Модуляции показаны полосами внизу плейлиста (закреплены, дорожки прокручиваются над ними): видно форму и повторы; клик — точка, тянуть — двигать, ПКМ — удалить.

## Пиано ролл

🖌 кисть / ⬚ выделение (рамкой, Shift — добавить) / 〰 изгиб (тянуть ноту вверх-вниз: к концу ноты высота уедет на столько ступеней). Ctrl+C / X / V, Delete, Ctrl+A, стрелки (Shift+↑↓ — на октаву), Esc. Громкость тянется сразу у всех выделенных. Зум: ↔ — по времени (Ctrl+колесо), ↕ — высота строк (Alt+колесо).

## LIVE

Кнопка LIVE в транспорте. Пока играет, выбор другого паттерна ставится в очередь (⏳) и включается на конце текущего. Клик по клавише, ноте или шагу звучит не сразу, а на ближайшей 1/16 сетки.

## Ссылки

`https://<сайт>/dawn` открывает DAWN (демо или черновик), `https://<сайт>/dawn/<путь к .dawn>` — этот проект. 🔗 в транспорте копирует ссылку. Файлы `.dawn` лежат в локальном слое, поэтому ссылка на файл работает только у его владельца.

## Сохранение

- 💾 / Ctrl+S → `/home/nikita/Desktop/<имя>.dawn` через `VFS.writeFile`: файл в **локальном слое** посетителя, видит его только он. Открывается двойным кликом.
- Сэмплы хранятся путями (`/home/...` или `builtin:...`), не внутри файла.
- Черновик: при каждом изменении проект пишется в `localStorage` (`dawn.autosave`). При следующем открытии без файла DAWN предложит его восстановить.
