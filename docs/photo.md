# Фото: параллакс по глубине и 3D

Просмотрщик фото (`public/js/apps/photo/`) — три режима: 🖼 фото, 🌊 параллакс, 🧊 3D. Листать картинки папки — ‹ › по краям, ←/→, PageUp/PageDown, Home/End (режим сохраняется). В проводнике у картинок — превью (`ui/thumbs.js`: грузятся, когда видны, 128 px, кэш в Cache Storage `nos-thumbs`). Тяжёлое (глубина хорошего качества, 3D-сцены) считается заранее на компьютере автора тулчейном `tools/photo3d` — серверу не надо напрягаться.

## Файлы рядом с картинкой

| Файл | Кто делает | Что |
|---|---|---|
| `<картинка>.depth.png` | тулчейн (16 бит), браузер или сервер (8 бит) | Обратная глубина, растянутая на 0..1: белое — близко. ≤ 1024 по большей стороне |
| `<картинка>.scene.nvx` | только тулчейн | Воксельная сцена: `"NVX1"` · u32 длина JSON-заголовка · заголовок · int16 xyz × N · u8 rgb × N (см. `nvx.js`) |

Проводник показывает их отдельной свёрнутой группой внизу папки, рабочий стол прячет (`core/types.js: isSidecar`).

## Откуда берётся глубина

1. Файл рядом — главный путь (тулчейн).
2. Картинка из личного слоя посетителя (загрузил в браузер) — считается в браузере сразу и ложится рядом туда же.
3. Сервер: `GET /api/depth?path=` → готовая (200) или в очереди (202). Пока в очереди — кнопка «🧠 Посчитать в браузере».

**В браузере** (`depth.js`): Depth Anything V2 Small, квантованная (~27 МБ), через onnxruntime-web в воркере. Файлы — в своей `fs`: `/fs/usr/share/depth/{model.onnx, ort.wasm.min.mjs, ort-wasm-simd-threaded.mjs, ort-wasm-simd-threaded.wasm}`; кладёт их тулчейн («📦 Подготовить сайт»).

**На сервере** (`depth.py`): та же модель, один поток, только в тихие часы (будни 04–08, выходные 04–09 МСК) и при loadavg/ядра < 0.5; после очереди модель выгружается. Кэш — `NOS_DATA/depth/`. Зависимости (onnxruntime, numpy, Pillow) необязательны: без них `/api/depth` отвечает 404.

## Параллакс (`parallax.js`)

WebGL2, steep parallax: для каждого пикселя экрана идём от ближнего слоя к дальнему и берём первую поверхность, которая его закрывает — ближнее перекрывает дальнее без растягивания краёв. Ракурс — от курсора (сглаженно) плюс ползунки «Угол X/Y»; «Сила» — величина сдвига, «Фокус» — какая глубина стоит на месте. Ползунки — обычные регуляторы окна, значит цели проводков: LFO из «Генераторов» на «Угол X» — фото само покачивается.

## 3D (`scene3d.js`)

Одна сетка из видимых граней вокселей, «майнкрафтовое» затенение граней. Старт — с точки съёмки (сначала видно ту же картинку).
- **Облёт:** тянуть — вращать, правой/Shift — сдвиг, колесо — ближе/дальше.
- **🚶 Ходьба:** клик — захват мыши, WASD, пробел — прыжок, Shift — бегом. Гравитация на пол и на воксели (по блокам можно ходить), ступенька до ¼ роста.
- **📐 Пол по 3 точкам:** три клика по сцене — плоскость становится полом, сцена поворачивается под неё (хранится у посетителя, `store("photo.floor.<путь>")`). У сцен Minecraft пол найден тулчейном.
- **Рост** — масштаб: высота глаз над полом (и скорость шага).

## Тулчейн `tools/photo3d`

```sh
uv run tools/photo3d/toolchain.py           # веб-интерфейс http://127.0.0.1:8770
uv run tools/photo3d/toolchain.py depth *.jpg --model base
uv run tools/photo3d/toolchain.py scene shot.png --mode minecraft
uv run tools/photo3d/toolchain.py site      # модель и рантайм для браузера/сервера → fs/usr/share/depth
```

- `depthmodel.py` — Depth Anything V2 (small / base / large, ONNX, кэш `~/.cache/nos-photo3d`), видеокарта, если onnxruntime её видит.
- `scene.py` — сцена:
  - **Фото:** глубина относительная, поэтому «Диапазон» — во сколько раз дальнее дальше ближнего; «Разрешение» — вокселей поперёк кадра. Пиксели вдали рассыпаются на несколько точек — без дыр. Небо (почти нулевая глубина) не строится.
  - **Minecraft:** нормали → три главных направления (оси мира), «верх» — ближайшее к верху камеры; размер блока и сдвиг сетки — по тому, как плоскости ложатся на k·s + o (берётся самый крупный шаг с почти лучшей оценкой, иначе ловится s/2); диапазон глубины подбирается сам — тот, при котором сетка садится лучше всего (грубо, потом уточнение). Мир в блоках: 1 блок = 1. Руками можно задать FOV (по умолчанию 70), диапазон и «блоков до центра кадра».
  - **Дозаполнить скрытое:** фото — слой фона за краями ближних предметов (глубина — минимум по окрестности, цвет — инпейнт OpenCV), только внутри кадра; Minecraft — столбцы досыпаются вниз до земли соседних столбцов.
- Веб-интерфейс (`web/`) берёт three.js и читалку `.nvx` прямо из `public/` репозитория — превью сцены выглядит как на сайте.
