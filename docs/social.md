# Аккаунты, чат, записи, комментарии

## Аккаунты (`chat.py`)

- Ник `^[A-Za-z0-9_\-А-Яа-яЁё]{3,20}$`, пароль 6–128, хэш scrypt.
- Сессия — случайный токен в cookie `nos_chat` (HttpOnly, SameSite=Strict, 60 дней).
- Неудачные входы ограничены по IP, регистрация — 1 с IP в 30 дней; IP регистрации и входов — в `ip_log` (на случай противоправного контента).
- Остальные модули получают пользователя только через `chat.user_by_token(request)`.

## Чат (`chat.py` + `apps/chat.js`)

- Общий чат — WS `/api/chat/ws`, хранится последняя 1000 сообщений, история страницами (`/api/chat/history`).
- **Личка — P2P WebRTC DataChannel.** Сервер только пересылает offer/answer/ICE и только между теми, кто оба согласились (запрос → согласие). Согласия сервер держит в памяти, клиент присылает свой список при подключении. История лички — в `localStorage`.
- Весь чужой текст — `textContent`.

## Записи («твиты», `posts.py` + `apps/post.js`)

- Название ≤ 80, текст ≤ 560, одна картинка ≤ 256×256, ≤ 64 КБ (жмёт браузер).
- Частота: пока в системе < 64 постов — раз в 30 минут, дальше — раз в UTC-сутки. ≤ 60 записей на пользователя.
- Править, менять картинку, удалять — только автор.
- Склад картинок переполнен → у старых записей снимаются картинки, текст остаётся.
- Жалобы: 2 разных жалобщика (не автор) → картинка скрыта до решения админа (`/api/mod/*`).
- `openPost(path)`, `createPost(dir)`, `openPostById(id)`; черновики в локальной папке — см. [filesystem.md](filesystem.md).

## Комментарии (`apps/comments.js`)

`mountComments(host, {room, me, postAuthor, onJump}) → {destroy}`.
Комнаты по WS: `post:<id>` — комменты поста, `posts` — глобальная лента (в ней можно только отвечать, ответ уходит в пост). Автор поста может удалять любые комменты в своём посте. Удалили пост → `chat.drop_comments(pid)`.
