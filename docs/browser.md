# Браузер и псевдо-сайты

## Браузер (`apps/browser.js`)

Окно с адресной строкой, ←/→/⟳/⌂ и 🔗 (копировать ссылку). Ходит **только** по сайтам из реестра `SITES`; неизвестный адрес — страница «Сайт недоступен».

- Адрес: `хост/путь?query`, напр. `kursk.artists/general/<tid>?page=2`. `about:home` — закладки.
- История — своя, на окно (`hist`, `pos`). `go(addr, replace)`, `step(±1)`, `reload()`.
- **Прямые ссылки:** `https://сайт/browser/<адрес>`. Сервер отдаёт на `/browser/*` обычный `index.html`, `main.js` видит путь и открывает браузер на этом адресе. Пока окно браузера активно, его адрес отражается в настоящей адресной строке (`history.replaceState`), после закрытия — `/`.
- Поэтому в `index.html` все пути абсолютные (`/style.css`, `/js/main.js`).
- Внутренние ссылки в контенте: `<a data-nav="адрес">` — перехватываются окном.

### Новый сайт

```js
const MySite = { title: "…", async render(b, parts, query) { b.paint(node); },
  enter(b) {}, leave(b) {} };       // необязательно: зашли на сайт / ушли с него (или закрыли окно)
SITES["my.site"] = MySite;          // + закладка в homePage()
```

`b` даёт `go`, `reload`, `paint`, `scrollEnd`, `addr`, `w` (окно), `view`. Большой сайт подключай лениво, как NETWORK (`import()` внутри `render`).

## Общее: вход, Markdown, треки

- **Вход** — одно окно на всю систему: `askAuth({why})` из `ui/auth.js` → ник или `null`. После входа — событие `nos-auth` (чат его слушает). Страница `kursk.artists/login` оставлена для старых ссылок и просто открывает это окно.
- **Markdown** — `apps/mdkit.js`: `md()`, `mdEditor({max, imgApi, extra, onLimit, hint})`. `onLimit` зовётся, когда текст упёрся в потолок (NETWORK — скретч и тряска окна), `hint` — подсказка, как открыть эмодзи с клавиатуры (по ОС).
- **Треки в тексте** — `[[track:/путь/файл.mp3]]` или `.dawn`. `trackcard.js` превращает в карточку: аудио → плеер маленьким окошком справа сверху (`Player.open(path, {mini: true})`), `.dawn` → играет мини-плеер DAWN прямо в карточке (`dawn/miniplayer.js`, окна DAWN не открываются), кнопки и ПКМ: открыть в DAWN, показать в ФС, скачать.

## Форум Kursk Artists (`kursk.artists`)

Клиент — объект `KA` в `browser.js`, сервер — `forum.py`. Аккаунт общий с чатом (вход на странице `kursk.artists/login` зовёт `/api/chat/auth`).

### Маршруты сайта

| Адрес | Страница |
|---|---|
| `kursk.artists` | Разделы |
| `kursk.artists/<раздел>` | Ветки раздела (`?page=`) |
| `kursk.artists/<раздел>/new` | Новая ветка |
| `kursk.artists/<раздел>/<tid>` | Ветка (`?page=N` / `?page=last`) |
| `kursk.artists/user/<ник>` | Профиль (свой — с редактором) |
| `kursk.artists/login?back=` | Вход / регистрация |

Разделы — словарь `SECTIONS` в `forum.py` (пока `general: "Общий"`).

### API

| Метод | Путь | Что |
|---|---|---|
| GET | `/api/forum/sections` | Разделы со счётчиками |
| GET | `/api/forum/s/{sec}?page=` | Ветки (свежие сверху) |
| GET | `/api/forum/t/{tid}?page=` | Ветка и посты |
| POST | `/api/forum/threads` | `{section, title, text}` — ветка + первый пост |
| POST | `/api/forum/t/{tid}/posts` | Ответ |
| PATCH / DELETE | `/api/forum/p/{id}` | Правка / удаление (автор; первый пост = вся ветка) |
| POST | `/api/forum/img` | JPEG ≤ 800px, ≤ 120 КБ → `{url}` для Markdown |
| GET | `/api/forum/u/{nick}` | Профиль |
| PATCH | `/api/forum/me` | `{about, city, site}` |
| POST / DELETE | `/api/forum/me/avatar` | Аватарка ≤ 256px |
| GET | `/media/f/{id}` | Картинка |

Лимиты: ветка раз в 10 мин, пост раз в 20 с, 30 картинок в сутки.

**Склад картинок.** У каждого свой — `NOS_FORUM_USER_MB` (10 МБ) на форум: полон — новую картинку не примем, пусть удаляет старые посты (под редактором — полоска «занято / 10 МБ», `GET …/quota`). Общий склад форума: Kursk Artists — `NOS_FORUM_STORE_CAP` (50 МБ), NETWORK — `NOS_NETFORUM_STORE_CAP` (150 МБ); переполнение — удаляются самые старые картинки постов, аватарки не трогаем. Удалили пост или ветку — удаляются и картинки из него. Раз в сутки уборка: картинки постов старше суток, на которые не ссылается ни один пост (загрузили и не отправили, убрали правкой), удаляются.

### Markdown

`md(src)` в `browser.js` — свой мини-рендер: **сначала экранирует весь текст**, потом размечает. Поддержка: заголовки `#..###`, `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` ``, блоки ```` ``` ````, `>` цитаты, списки, `---`, ссылки и автоссылки.
Картинки — только с `/media/...` (чужие адреса не грузим). Ссылки на `kursk.artists/…` и `…/browser/…` нашего сайта открываются внутри браузера.
Редактор `mdEditor()` — панель кнопок, загрузка картинки (вставляет `![картинка](/media/f/…)`), превью.


## NETWORK (`net.work`)

Нетворкинг-сайт для криейтеров. Клиент — `apps/net/` (`site.js` — страницы, `wall.js` — стена, `sfx.js` — звуки, `data.js` — заготовки тегов, статусов и распознавание ссылок), сервер — `network.py` + второй экземпляр `forum.Forum` (`/api/net/forum`, свои разделы, аватарки постов из профилей NETWORK через `decorate`).

### Маршруты

| Адрес | Страница |
|---|---|
| `net.work` | Главная: счётчики, свежие лица, свежие ветки |
| `net.work/forum[/<раздел>[/<tid>\|/new]]` | Форум (как у Kursk Artists, + треки, эмодзи-подсказка, звуки) |
| `net.work/people?q=&tags=a,b&status=&seeks=&loc=&game=&web=1&on=1&page=` | Люди с фильтрами (фильтры пишутся в адрес без перерисовки) |
| `net.work/match` | «Найди мне своих» — подбор с объяснением «почему» |
| `net.work/wall` | Общая стена граффити |
| `net.work/u/<ник>` | Профиль |
| `net.work/me`, `net.work/join` | Свой профиль (редактор / первая анкета), вступление |
| `net.work/dm`, `net.work/dm/<ник>` | Личные сообщения: разговоры / диалог |

### Профиль

Имя ≤ 40; аватарка — кружок, ≤ 400px, ≤ 180 КБ, жмётся мягко (качество от 0.92); ссылки ≤ 30 (известные сайты распознаёт `linkKind`, остальные подписывает человек); деятельность ≤ 30 тегов (подсказки: заготовки `ACTIVITIES` + теги, которые уже кто-то указал, `/api/net/tags`; свой тег — Enter); статус: `collab` (wanna collab + роли), `looking` (looking for + роли), `creating`, `busy`, `with` (working on a collab with + с кем), `idle` (don't do shit atm); локация — город, страна, web only; «о себе» ≤ 1000 (Markdown); треки ≤ 6 — любые аудио / `.dawn` из ФС.

Свои mp3: ≤ 2 файла по ≤ 12 МБ в `/home/network/<ник>` (настоящие файлы общего слоя, видны в проводнике). Загрузка — потоком, проверка заголовка mp3, склад всех mp3 — `NOS_NET_MP3_CAP_MB` (500 МБ): полон — новые не принимаем, старые не трогаем.

### В сети и личные сообщения

**В сети** — зелёная точка у аватарки (карточки, посты, профиль, разговоры). Сервер считает человека онлайн 75 с после любого его запроса к NETWORK; клиент, пока вкладка видна, пингует `/api/net/ping` раз в 25 с (ответ — число непрочитанных, бейдж у «Сообщений», новое — бип). Открытый чат nikita.os тоже считается.

**Личка** хранится на сервере (не P2P, как в чате): SQLite `.meta/netdm.db`, таблицы `dm(a → b, text, t, seen)` и `dm_block`. Писать может только тот, у кого есть профиль NETWORK, и только тем, у кого он есть. Текст ≤ 2000, не чаще раза в 0.8 с, ≤ `NOS_NET_DM_DAY` (400) в сутки, в разговоре живут последние `NOS_NET_DM_KEEP` (2000). Блок: заблокированный не может писать, его непрочитанные не считаются. Клиент: диалог опрашивает сервер раз в 4 с (новые + галочки ✓/✓✓ «прочитано»), старые — подгрузкой при прокрутке вверх. Текст выводится только текстовыми узлами, ссылки http(s) — кликабельны.

**Сейчас играет** — до 20 игр в профиле (регистр сохраняется; подсказки — игры, которые указали другие, `/api/net/tags` → `games`). Фильтр людей `game=`, в подборе общие игры +1.5 («оба играют в …»).

### Подбор

Очки: человек ищет роль, которая есть у тебя (+5 за каждую), ты ищешь его роль (+5), общие теги (+2), тот же город (+3) / страна (+1.5), оба в вебе (+1), статус (коллаб/ищет +1.5, занят −0.5, ничего не делает −1), чуть выше — недавно обновлённые. Каждому — список причин.

### Стена граффити

Мир 1600×900. Три холста: кирпичная кладка (из сида: кирпич 92×32, тонкий шов 2px, тон каждого кирпича свой), краска, рельеф поверх краски (поэтому кирпичи и шероховатости видно сквозь краску); в ямки краска ложится хуже. Штрих = `{c, k, s, p: [x, y, dt, …]}`: цвет (10), кэп (skinny / standard / fat), сид, точки. Краска кладётся пшиками по времени (быстро — тонко, задержался — густо и течёт) и по расстоянию (быстрый штрих не рвётся), подтёки считаются из самого штриха — у всех одинаковые. Один и тот же `StrokeRenderer` рисует вживую и при загрузке.

**Запекание.** Сервер хранит только свежие штрихи (`.meta/netwall.jsonl`, в памяти — готовыми JSON-строками, ≈ размер файла), а старую краску — одной картинкой (`.meta/netwall_bake.webp`). Сервер рисовать не умеет и чужие картинки стены не принимает, поэтому запекает браузер владельца (`NOS_NET_WALL_ADMIN`, по умолчанию `cojam`): открыл стену, а незапечённых ≥ 300 — слой краски уходит на сервер сам; есть и кнопка «🔥 запечь». Сервер проверяет формат и размер по заголовку (PNG/WebP 1600×900, ≤ 8 МБ) и удаляет штрихи до `upto`. Нарисованное остаётся навсегда. Если долго не запекать, после `NOS_NET_WALL_STROKES` (2500) незапечённых самые старые уходят.

**Кто где рисовал** — `.meta/netwall_log.jsonl`: `{id, u, t, b: [рамка]}` на штрих, для модерации (после запекания стереть чужую краску нельзя — только закрасить).

Ограничения: ≤ 250 точек и ≤ 9 с на штрих, ≤ `NOS_NET_WALL_DAY` штрихов на человека в сутки. Новое от других — опрос раз в 3.5 с.

### Звуки (`sfx.js`, синтез, громкость — общая с «Откликом»)

Запрет (лимит символов, ошибка сервера, нет прав) — скретч пластинки + окно трясётся (`deny`). Пост / ветка — «динь». Профиль сохранён — шарик в баллончике и «пшшш». Стена — живой пшик, пока зажата кнопка; щелчок кэпа при смене цвета/кэпа. Переходы (`navSound`): страница — «шух», ветка и окошки — щелчок, профиль и вход — бип вверх, выход — вниз, стена — гремит баллончик, «найди своих» — свист; мелочи (кнопки панели, теги, статусы, страницы списка) — тик, удаление — глухой удар. Действие, у которого был свой звук и которое потом перерисовывает страницу, зовёт `hush()` — переход промолчит.

### Оформление

Розовый / чёрный / зелёный, панк. Шрифты Rubik Wet Paint (лого) и Rubik Spray Paint (заголовки) — `public/vendor/fonts/`, лицензия OFL. Лого `NETWORK` и подтёки крепятся к **окну** браузера (`enter`/`leave`), окну на это время даётся `overflow: visible` (класс `nw-win`), поэтому лого вылезает за край, а низ окна «подтекает»: подтёки — тонкие струйки, розовые и чёрные, размеры в пикселях (не тянутся с окном); справа густой «куст», слева редкие и короткие; струйка «дышит», с кончика срывается круглая капля (отдельный элемент — не тянется вместе со струйкой).
