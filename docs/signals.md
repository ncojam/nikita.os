# Шина сигналов ОС

«Всё — параметр, всё — сигнал» (см. [philosophy.md](philosophy.md)). Источник тянет провода к любым параметрам ОС; шина складывает провода и применяет значения 30 раз в секунду. Сохранённые значения никто не переписывает: снял провод — параметр вернулся.

## Части

| Файл | Что |
|---|---|
| `core/signals.js` | Значение источника 0..1 (`srcValue`): ручка, огибающая, LFO, ветер, по ноте, уровень инсерта, **курсор** (`mouse`), **громкость плеера** (`level`) |
| `core/bus.js` | `Bus`: системная стойка `Bus.rig` (localStorage `rig`), клиенты, тик, цели (`targets`), подписи (`label`). `init_bus()` из `main.js` — стойка работает сразу после перезагрузки |
| `core/params.js` | Реестр целей: провайдеры `os.`, `bg.`, `ui.`, `win.`, `rig.` (`Params.addProvider`) |
| `core/uiparams.js` | Любой `<input type=range|number>` и крутилка любого окна — цель `ui.<ключ окна>#n`; эффекты окон `win.<ключ|*>.shake|tilt|zoom|fade|jump` |
| `apps/rig/` | Окна системной стойки: «Автоматизация», «Генераторы», «Педали ОС», отдельная педаль |
| `apps/dawn/mod.js` | Окно источников: одно на DAWN и на стойку (разница — «область» `scope`), провода-верёвки поверх экрана |
| `core/cmd.js`, `apps/scripts.js` | Команды окон ⌘ и скрипты `.nos` |
| `ui/grid.js` | Грид выбора |

## Системная стойка

```js
Bus.rig = { v: 1, bpm: 120, mods: [источник…], pedals: [{ id, type, on, p }] }
```

- Источник — как в DAWN (`core/signals.js`), id начинается с `s`. Часы стойки — свои: `Bus.beat()` по `rig.bpm` (LFO и огибающие).
- **Клиенты** (`Bus.attach(id, {...})`): модуль со своими источниками и целями. DAWN — клиент `dawn`: его провода и провода стойки складываются, провод стойки может идти в крутилку DAWN (пока DAWN открыт), провод DAWN — в окно ОС.
- **Педали ОС** (`apps/rig/pedalboard.js`): каждая педаль — узел звука ОС `pedal:<id>` со своим входом и выходом; где она стоит, решают кабели (см. «Звук ОС»). Эффекты из `dawn/fx.js` кроме сайдчейна; выключенная пропускает звук насквозь. Ручки — цели `rig.<id>.<параметр>`.
- **Педалборд — один экземпляр:** одно окно, педалей сколько угодно. Любую можно ⧉ вынести своим маленьким окном (`rig:pedal:<id>`) — это второй вид той же педали, звук не дублируется.

## Провода поверх окон

Кнопка 🔌 на панели задач (и «🔌 Провода» в окнах модуляции) — один общий переключатель (`Mod.setShowWires`, localStorage `wires.show`, событие `nos-wires`). Включён — провода всех источников (системная стойка и DAWN) рисуются поверх открытых окон. Если окно источника закрыто, его гнездо стоит в доке у правого края экрана: провода тянутся оттуда, из гнезда можно тянуть новый провод, клик по имени — открыть окно источника.

## Пуск

Приложения → 🎵 Музыка → под «🌸 DAWN»: «🔌 Автоматизация» (ручки, огибающие, курсор, громкость плеера), «∿ Генераторы» (LFO, ветер), «🎛 Педали». Всё работает без открытой DAWN.

## Грид — шаблон выбора (`ui/grid.js`)

Слева направо — категории, вниз — квадратики, сверху — поиск (Enter — первый найденный).

```js
grid({ columns: [{ title, color, items: [{ value, label, sub, icon, color, title }] }], onPick, value })   // узел
pickGrid({ anchor, title, columns, value }) → Promise<item | null>                                         // всплывашка
gridButton({ label, title, columns | () => columns, value, onPick })                                       // кнопка
```

Где сейчас: «＋ цель…» у источника модуляции (колонки — группы целей), «✨ Пресет» у инструмента DAWN (колонки — категории `presetColumns`).

## Команды и скрипты

Кнопка ⌘ в заголовке окна → команда, которая откроет такое же окно с теми же настройками там же. `w.cmd()` задают приложения с настройками (проводник — папка, браузер — адрес, фото — режим и ползунки, окна стойки — весь её состав); остальные узнаются по ключу окна (`file:…`, `dawn:…`, `settings`…). В конец добавляется `place x y w h`.

Синтаксис: команда на строку, слова через пробел, `"строки в кавычках"`, хвост с `{`/`[` — JSON, `#` — комментарий. Ошибка в строке не останавливает скрипт.

| Команда | Что |
|---|---|
| `open <путь>` | Файл или папка |
| `app <имя> [путь]` | Приложение (как `app` в ярлыке `.lnk`) |
| `photo <путь> [flat\|parallax\|3d] [{…}]` | Просмотрщик фото в режиме и с настройками |
| `dawn [проект]`, `dawn.win <модуль> [арг]` | DAWN и её окна |
| `rig.open auto\|gen\|pedals\|pedal <id>` | Окна стойки |
| `rig.bpm`, `rig.clear` | Темп часов ОС, очистить стойку |
| `rig.src <id> <тип> [{…}]` | Источник (`knob env lfo wind mouse level`); тот же id — заменить |
| `rig.wire <id> <адрес> [сила]` | Провод |
| `rig.pedal <id> <тип> [off] [{…}]` | Педаль ОС |
| `place x y w h` | Положение и размер окна из предыдущей команды |
| `wait <мс>`, `say <текст>` | Пауза, уведомление |

Новая команда — `Cmd.add(имя, использование, описание, async (args, ctx) => {...})`; открыла окно — положи его в `ctx.win` (для `place`).

## Звук ОС

`core/audio.js` — один `AudioContext` на всю ОС и граф с кабелями, как на пульте.

- **Узлы:** источники (плеер `player`, деки пульта `dj.a`/`dj.b`), обработка (педали `pedal:<id>`), выход (микшер ОС `mixer` → колонки). `AudioOS.register({ id, title, icon, kind, input(from), output })`.
- **Кабели:** `{ from, to }` в localStorage `audio.routes`. Новый источник при первом появлении сам подключается в микшер; дальше — как провёл: вынул кабель — тишина, плеер → педаль → микшер — звук через педаль. Петли и дубли не пускаются. Узла сейчас нет (окно закрыто) — кабель ждёт и оживает, когда он появится.
- **Микшер ОС:** полоса на каждый кабель в микшер (громкость, выкл, индикатор) и мастер; `audio.mix`.
- **Приложение «🔊 Звук»** (`apps/sound.js`): сверху коммутация (тянуть от ● выхода к ● входу, клик по кабелю — вынуть; отсутствующие узлы — бледные), снизу микшер. Ползунки — цели проводков.
- **Команды:** `audio.route <откуда> <куда>`, `audio.unroute <откуда> <куда>`; ⌘ окна «Звук» и педалборда отдаёт и кабели.
- DAWN пока живёт в своём `AudioContext` и в граф не входит.
