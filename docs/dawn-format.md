# Формат проекта DAWN — `dawn/2`

`.dawn` — обычный JSON в UTF-8. Формат задуман так, чтобы его одинаково легко читали и писали **люди и нейросети**:

- **время — в долях** (четвертях): `0.25` — шестнадцатая, `1` — четверть, `4` — такт 4/4;
- **высоты — именами нот**: `"C4"` (= MIDI 60), `"F#3"`, `"Bb2"`;
- **ссылки — короткими понятными id** (`"kick"`, `"lead"`, `"verse"`);
- **всё необязательное можно пропускать** — подставятся значения по умолчанию, а неизвестные поля игнорируются.

> **Для нейросетей есть инструкция прямо в приложении:** окно 🤖 «Проект как текст» → «🤖 Дока + проект» (доработать трек), «📘 Только дока» (написать с нуля), «📋 Только проект». Инструкция генерируется из кода DAWN (`schema.js → aiDoc()`), поэтому новые функции попадают туда сами. Этот документ — для людей.

Там же «⬆ Загрузить из текста»; обёртку ```json, которую любят добавлять нейросети, загрузчик срезает сам.

## Минимальный пример

```json
{
  "format": "dawn/2",
  "name": "Tiny",
  "bpm": 100,
  "channels": [
    { "id": "kick", "type": "sampler", "sample": "builtin:kick" },
    { "id": "bass", "type": "osc3", "scale": { "root": "E", "mode": "minor" } }
  ],
  "patterns": [
    { "id": "loop", "sig": "4/4", "notes": {
        "kick": [[0, 0.25, "C4"], [1, 0.25, "C4"], [2, 0.25, "C4"], [3, 0.25, "C4"]],
        "bass": [[0, 0.5, "E2", 0.9], [1.5, 0.5, "G2"], [2, 1, "B1"]] } }
  ],
  "playlist": [{ "pattern": "loop", "track": 1, "start": 0, "length": 16 }],
  "mode": "song"
}
```

## Корень

| Поле | Тип | По умолчанию | Что |
|---|---|---|---|
| `format` | `"dawn/2"` | — | метка формата |
| `name` | строка | `"Трек"` | название |
| `bpm` | 40..300 | 128 | темп |
| `swing` | 0..0.6 | 0 | свинг шестнадцатых |
| `mode` | `"pat"` \| `"song"` | `"pat"` | что играет: текущий паттерн по кругу или плейлист |
| `current` | id паттерна | первый | выбранный паттерн |
| `channels` | массив | — | инструменты (стойка каналов) |
| `patterns` | массив | — | паттерны с нотами |
| `playlist` | массив | `[]` | клипы песни |
| `mixer` | массив | Master + 8 инсертов | микшер |
| `live` | bool | false | LIVE: паттерн переключается на конце текущего |
| `mods` | массив | `[]` | источники модуляции с проводками (ниже) |
| `pedals` | массив | `[]` | эффекты-педали вне микшера (ниже) |
| `layout` | объект | — | раскладка окон (только для интерфейса, нейросети можно не трогать) |

## `channels[]`

| Поле | Что |
|---|---|
| `id` | короткий id, на него ссылаются ноты паттернов |
| `type` | `"osc3"` (синтезатор 3XOSC), `"grapefruit"` (FM) или `"sampler"` |
| `flash` | необязательно: цвет вспышки фона `"#rrggbb"` или `null` (выкл); без поля — бочка/малый вспыхивают по умолчанию |
| `params.uni` / `udet` / `uspr` | 3XOSC: голоса unison 1..8, расстройка 0..100 центов, стерео 0..1 |
| `poly` | 1..32, по умолчанию 16 — сколько голосов одновременно (1 — моно) |
| `name`, `color` | подпись и цвет `#rrggbb` |
| `vol` 0..1.25, `pan` −1..1, `mute`, `solo` | полоса канала |
| `mixer` | номер инсерта микшера (0 — сразу в Master) |
| `edo` | строй: `12` (по умолчанию), `24`, `19`, `31`, `17`, `22`, `5`, `7` — на сколько равных ступеней делится октава |
| `scale` | `{ "root": "C", "mode": "minor", "snap": false }` — лад для подсветки в пиано ролле; `snap` — ноты прилипают к ладу |
| `sample` | только для `sampler`: `"builtin:kick"`, `"builtin:snare"`, `"builtin:clap"`, `"builtin:hat"`, `"builtin:openhat"`, `"builtin:tom"` или путь в ФС сайта (`"/home/nikita/…/x.wav"`) |
| `params` | параметры инструмента (ниже) |

**3XOSC** — `params`:

```json
{ "oscs": [ { "wave": "sawtooth", "o_vol": 0.55, "o_crs": 0, "o_fin": -6, "o_pan": -0.2 }, { … }, { … } ],
  "att": 0.005, "dec": 0.3, "sus": 0.6, "rel": 0.3, "cut": 6000, "res": 1.2 }
```

`wave`: `sine` / `triangle` / `sawtooth` / `square` / `noise`; `o_crs` — полутоны (−24..24); `o_fin` — центы; огибающая `att/dec/rel` — секунды, `sus` 0..1; фильтр `cut` 40..18000 Гц, `res` 0.1..18.

**Grapefruit** (FM, 4 оператора) — `params`: `preset` (`"E-Piano"`, `"Bell"`, `"FM Bass"`, `"Glass Pad"`, `"Pluck"`, `"Neuro Bass"`, `"Riddim FM"`, `"Metal Pluck"`, `"Digital Keys"`, `"Sub FM"`) — с него стартуем, а `ops` и `mod`, заданные явно, его перекрывают; `cut`, `res`.
- `ops[]` — `{ wave, ratio, oct, fine, level, out, pan, att, dec, sus, rel, harmonic, harm, env }`: `wave` — `sine|triangle|sawtooth|square|organ|pulse|hollow|custom`; частота оператора = нота · `ratio` · 2^`oct` (`ratio` до 0.0001, `oct` −4..4); `harmonic: true` — ratio прилипает к гармоникам; `harm` — 8 амплитуд гармоник для `custom`; `pan` −1..1.
- `env` — нарисованные огибающие: `{ vol|pan|pitch: { on, sus, pts: [[секунды, 0..1], …], range } }`; `sus` — индекс точки удержания (−1 — без), `range` у `pitch` — полутоны. Включённая `vol` заменяет ADSR оператора.
- `mod` — матрица `mJK` для любой пары (J — кто модулирует, K — кого): старший → младшему напрямую, младший → старшему — обратная связь через задержку ~3 мс.

**Sampler** — `params`: `root` (MIDI-нота, на которой записан сэмпл, 60), `tune` (−12..12 полутонов), `start` (0..0.95 — откуда играть), `att`, `rel` (с), `oneshot` (играть до конца, игнорируя длину ноты), `rev` (задом наперёд).

## `patterns[]`

| Поле | Что |
|---|---|
| `id`, `name`, `color` | |
| `sig` | размер: `"4/4"`, `"7/4"`, `"11/4"`, `"6/8"`… (знаменатель 1, 2, 4, 8 или 16) |
| `length` | длина в долях; не указана — по нотам, целыми тактами. Может быть дробной (`3.5`, `7.25`) |
| `notes` | `{ "<id канала>": [[start, length, pitch, velocity], …] }` |

Нота — массив `[start, length, pitch, velocity]` (или объект `{ "start", "length", "pitch", "vel" }`):

- `start`, `length` — доли от начала паттерна;
- `pitch` — имя ноты `"C4"` / `"F#3"` / `"Bb2"`. Ударным обычно ставят `"C4"`. Можно и число — номер ступени (в 12-EDO это MIDI);
- `velocity` 0..1, по умолчанию 0.8;
- пятый элемент (необязательный) — **изгиб**: к концу ноты высота плавно уедет на столько ступеней строя (минус — вниз).

### Высоты в других строях

Номер ступени: `n = (октава + 1) · edo + ступень`, частота `f = 8.1758 · 2^(n / edo)` Гц. В 12-EDO это ровно MIDI.

| Строй | Как писать высоту |
|---|---|
| 12 | `"C4"`, `"F#3"` |
| 24 | `"C4"`, `"C↑4"` (↑ — на четверть тона выше), `"C#↑4"` |
| 19 | `"C4"`, `"C#4"`, `"Db4"`, `"E#4"`, `"B#3"` (у 19-EDO C# и Db — разные ступени) |
| 31, 17, 22, 5, 7 | `"октава:ступень"`, например `"4:7"` |

Лады (`scale.mode`) для каждого строя:

| Строй | Лады |
|---|---|
| 12 | `chromatic`, `major`, `minor`, `dorian`, `phrygian`, `lydian`, `mixolydian`, `locrian`, `harmminor`, `melminor`, `pentmaj`, `pentmin`, `blues`, `hirajoshi`, `inscale` |
| 24 | `chromatic`, `rast`, `bayati`, `saba`, `hijaz`, `sikah`, `major`, `minor` |
| 19 | `chromatic`, `major`, `minor`, `pent`, `negri` |
| 31 | `chromatic`, `major`, `minor`, `neutral`, `orwell` |
| 17 | `chromatic`, `major`, `neutral` |
| 22 | `chromatic`, `major`, `porcupine`, `pajara` |
| 5, 7 | `chromatic` |

## `playlist[]`

`{ "pattern": "<id>", "track": 1.., "start": доли, "length": доли }`. Если клип длиннее паттерна, паттерн повторяется. Сетка плейлиста — 4/4, а паттерны в 7/4 и т. п. просто занимают свою длину.

## `mixer[]`

Индекс 0 — **Master**, дальше инсерты 1, 2, … Каналы попадают сюда по `channels[].mixer`.

```json
{ "name": "Lead", "vol": 0.8, "pan": 0, "mute": false,
  "fx": [ { "type": "delay", "on": true, "sync": 2, "fb": 0.38, "mix": 0.3, "damp": 5000, "pp": 1 },
          { "type": "reverb", "on": true, "decay": 2.2, "pre": 0.02, "damp": 7000, "low": 120, "mix": 0.25 } ] }
```

Не больше 4 эффектов на инсерт, они идут по порядку.

| Эффект | Параметры |
|---|---|
| `delay` | `sync` 0..6 (1/16, 1/8, 1/8., 1/4, 1/4., 1/2, такт), `fb` 0..0.92, `mix` 0..1, `damp` Гц, `pp` 0/1 — пинг-понг |
| `reverb` | `decay` 0.3..8 с, `pre` 0..0.2 с, `damp` Гц, `low` Гц (срез низа), `mix` 0..1 |
| `eq` | `lf`/`lg` — низкая полка (Гц/дБ), `mf`/`mg`/`mq` — середина, `hf`/`hg` — верхняя полка; дБ −18..18 |
| `dist` | `drive` 0..1, `shape` 0 soft / 1 hard / 2 fold / 3 crush, `tone` Гц, `mix` 0..1, `out` 0..1 |
| `comp` | `thresh` −60..0 дБ, `ratio` 1..20, `attack`, `release`, `gain` — makeup |
| `ott` | многополосный «OTT»: `depth` 0..1, `time`, `low`/`mid`/`high` дБ, `out` |
| `side` | сайдчейн по нотам: `src` — id канала (обычно `"kick"`), `amount` 0..1, `attack`, `release` |
| `math` | формула над каждым сэмплом: `expr` — выражение от `x` (сэмпл), `t` (время, с), `a`, `b` (0..1); есть `sin`, `tanh`, `clip`, `fold`, `crush`…; `mix` |
| `code` | свой JS: `code` — тело функции `(x, t, a, b, ch, state, sr) → y`; `state` — память между сэмплами; `a`, `b`, `mix`. Работает в AudioWorklet (без DOM и сети) |

## `pedals[]` — педали

Эффект вне микшера: `{ "id": "pd1", "type": "dist", "on": true, "in": "ch:bass" | "mix:3", "out": "mix:0", …параметры эффекта }`. Вход канала берётся до инсерта, инсерта — после фейдера; звук идёт параллельно основному. Вход-инсерт ≠ выход, Master как вход нельзя. Параметры модулируются адресом `pedal.<id>.<параметр>`.

## `mods[]` — модуляция

```json
{ "id": "macro", "type": "knob", "name": "Macro", "value": 0,
  "wires": [ { "to": "ch.bass.cut", "amt": 0.25 }, { "to": "ch.lead.osc2.o_vol", "amt": 0.5 }, { "to": "os.hue", "amt": 0.3 } ] }
```

- `type`:
  - `knob` (`value` 0..1);
  - `env` (`env: { len, loop, pts: [[доля, 0..1], …] }`) — едет с песней; видно полосой под плейлистом;
  - `lfo` (`lfo: { sync, shape: sine|triangle|saw|square|random, phase }`);
  - `trig` (`trig: { ch, att, hold, rel, vel }`, мс) — огибающая, которую запускает каждая нота канала `ch` (провод с минусом на `vol` — сайдчейн);
  - `meter` (`meter: { mix, gain }`) — уровень инсерта микшера;
  - `wind` (`wind: { input, strength, gust }`) — ветер: качает провода на экране; `input` — id другого источника или пусто.
- Провод: `to` — адрес параметра, `amt` −1..1. Цель = база + amt · (v − центр) · диапазон; центр 0.5 у LFO, 0 у остальных.
- Адреса: `ch.<канал>.vol|pan|<параметр>`, `ch.<канал>.osc1.o_vol`, `ch.<канал>.op2.ratio`, `ch.<канал>.m21`, `mix.<инсерт>.vol|pan`, `mix.<инсерт>.<слот>.<параметр>`, `pedal.<id>.<параметр>`, `os.<id>` — параметры ОС из `etc/params.json`, `bg.<параметр>` — живой фон, `ui.<ключ окна>#<n>` — любой регулятор окна ОС, `win.<ключ окна | *>.shake|tilt|zoom|fade|jump` — эффекты окон.

## Совместимость

Файлы первого этапа (`"v": 1`: время в шагах 1/16, `notes[паттерн][канал]`) открываются и при следующем сохранении переписываются в `dawn/2`.
