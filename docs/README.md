# nikita.os — документация по коду

Личный сайт в виде настольной ОС: окна, рабочий стол, проводник, плеер, эмуляторы, чат, записи, браузер с псевдо-сайтами.
Бэкенд — Python (aiohttp, `server.py` + модули рядом), фронтенд — чистый JS-модули без фреймворков и без сборки (`public/`).

## Запуск

```sh
./run.sh            # сервер в фоне + открыть сайт (сам поставит aiohttp в .venv)
./stop.sh           # остановить
docker compose up -d --build   # продакшн, см. deploy.md
```

Сборки нет: правка `.js`/`.css` видна после перезагрузки страницы, правка `.py` — после перезапуска сервера.
