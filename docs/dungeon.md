# Clown Dungeon — игра для Telegram

Mini App: страница `/dungeon.html`, сервер `dungeon.py`, клиент `public/js/apps/dungeon/`. Текстового режима нет сознательно:
бой в такт и музыка DAWN возможны только в веб-приложении. Открыть можно и в браузере — войдёшь гостем.

| Файл | Что |
|---|---|
| `dungeon.py` | Вся игра: таблицы `ITEMS`, `ENEMIES`, `LOCATIONS`, бой, земля, сохранение (`data/dungeon.json`), WS `/api/dungeon/ws` |
| `public/js/apps/dungeon/index.js` | Экраны, связь, тапы |
| `public/js/apps/dungeon/view.js` | Холст боя. Враг рисуется только в `drawEnemy` |
| `public/js/apps/dungeon/music.js` | Играет паттерн через граф DAWN (`dawn/graph.js`), судит попадание в такт |
| `public/js/apps/dungeon/sfx.js` | Шаги, урон, подбор, хихиканье, победа, рюкзак: всё синтезируется, с эхом пещеры |
| `public/js/apps/dungeon/arrange.js` | Общий пресет аранжировки и разбор правил |
| `public/dungeon/music/` | Треки `.dawn` и необязательные правила `<id>.json` |

## Правила

- **Бродить**: веса исходов — `LOCATIONS[...]["wander"]`. Кнопка заполняется за `WANDER_CD`; нажатие за 0,25 с до готовности запоминается и срабатывает само (`WALK_BUFFER` в `index.js`).
- **Бой** по ходам: участники по очереди, затем враг. Атака, предмет и побег тратят ход, снаряжение — нет. На ход 30 с.
- **Комбо**: атака наносит удар, над врагом крутится нотка. Каждый тап по врагу в такт сильной ноте — ещё удар вдвое слабее предыдущего (`COMBO_DECAY`), минимум 1, без ограничения по числу. Одну сильную ноту можно пропустить; тап мимо такта или пауза заканчивают ход.
- **Присоединиться** к чужому бою: до 4 человек, новичок ходит в конце круга, музыка у него идёт с той же доли.
- **Помешать** (подножка, раз в 12 с): −1 HP цели, сбивает её комбо, а вне комбо вдвое ослабляет следующую атаку. Доступно зрителям и участникам.
- **Смерть**: рюкзак и монеты падают на локацию, надетое остаётся, HP восстанавливается. Добыча с врага тоже падает на пол. С земли берёт кто угодно, через 15 минут вещи исчезают.
- Отключившийся через 30 с выбывает из боя.
- **Уровни**: за победу каждый участник боя получает опыт (10 + 5 за уровень врага сверх первого), до следующего уровня нужно 30 × уровень. Уровень даёт +4 к здоровью, полное лечение и +1 к урону раз в 2 уровня.
- **Уровень врага** равен уровню игрока, который на него наткнулся: +12% здоровья за уровень, +1 к атаке раз в 2 уровня. Числа — константы вверху `dungeon.py`.
- **Выкинуть**: вещь из рюкзака ложится на локацию, ход не тратится. Надетое сначала нужно снять.

Попадание судит клиент (только он знает, что слышно в наушниках), сервер проверяет, что нота сильная, новая и близка по времени. Автокликер это не остановит — для игры без рейтинга приемлемо.

## Новый трек

Сохрани проект DAWN в `/home/nikita/Projects/ClownDungeon` на сайте под аккаунтом владельца: перед каждым боем сервер смотрит папку, и трек сразу попадает в случайный выбор. Деплой не нужен. Чужие проекты из этой папки не берутся, она общая на запись. Ещё треки лежат в `public/dungeon/music/`; файл с тем же именем в папке на сайте важнее.

Трек на бой выбирается случайно, два раза подряд один не повторяется. Ограничить врага своим списком: `"tracks": ["dungeon_01"]` в `ENEMIES`.

Роли определяются по названиям каналов: Kick, Snare, Hat, Bass, Bells/Lead, Suspence. Канал с непонятным именем вступает последним, а если мелодии не нашлось, ею станет первый синт. Сильные ноты — мелодия на целых долях. Чтобы задать всё вручную, положи `public/dungeon/music/<имя файла в нижнем регистре>.json`, там пишутся только отличия от пресета:

```json
{
  "pattern": "pattern",
  "roles": { "канал": "lead", "канал2": "bass", "choir": "pad" },
  "strong": { "channels": ["канал"], "grid": 1 },
  "addLayers": [{ "role": "pad", "at": 6 }],
  "rules": [{ "when": { "enemyHpBelow": 0.5 }, "add": ["pad"] }],
  "window": 0.055
}
```

`strong` — какие ноты считаются сильными: ноты этих каналов, попавшие на сетку `grid` (в долях). `window` — допуск тапа, с. Язык правил описан в шапке `arrange.js`. Канал без роли вступает последним.

## Модель врага из Blender

Формат — `.glb` (glTF Binary), файл `public/dungeon/enemies/<kind>.glb`. Он один содержит геометрию, текстуры и все анимации.

- Масштаб: голова примерно 1 м, центр объекта в центре головы, смотрит на камеру по −Y. Scale применён (Ctrl+A).
- До 10 000 треугольников, текстура 1024 максимум, файл до 2 МБ. Материал — Principled BSDF: нодовые эффекты в glTF не переносятся.
- Каждая анимация — отдельный экшен в Action Editor с таким именем: `idle` (цикл), `hit`, `hit_heavy`, `attack`, `death`, `intro`. Те же имена у состояний в `drawEnemy`. Нужно больше — добавляй, лишние не мешают.
- Двигать через арматуру, shape keys или сам объект — всё поддерживается. Драйверы и симуляции нужно запечь (Bake Action).
- `idle` сделай с совпадающими первым и последним кадром. Точное число кадров неважно: при подключении растянем цикл под темп.
- У `attack` момент удара отметь маркером `impact`: враг бьёт в долю музыки, старт анимации подгоним по нему.
- Экспорт: File → Export → glTF 2.0, формат glTF Binary; Include: Selected Objects; Mesh: Apply Modifiers; Animation: Mode **Actions**, Shape Keys включить, Sampling включить. Draco не включать (нужен отдельный декодер).

Показ модели ещё не подключён: это будет three.js, навендоренный в `public/vendor/`, вместо прямоугольника в `drawEnemy`.

## На сайте

Окно с игрой: Пуск → Приложения → Clown Dungeon или ярлык на рабочем столе. Это та же страница в iframe (`/dungeon.html?site=1`): с параметром она отдаётся с заголовками изоляции, без которых браузер не покажет её внутри ОС. Вошедшие играют под ником сайта и сохраняют прогресс, остальные — гостями.

## Telegram

В @BotFather создать бота (или Mini App у бота Джуса) с адресом `https://<сайт>/dungeon.html`. Токен — в `/opt/site/.env` как `TG_DUNGEON_BOT_TOKEN`; если бот тот же, хватит `TG_BOT_TOKEN`. Без токена игроки входят гостями и прогресс не сохраняется.
