# Философия и сквозные механизмы

## Принципы

- **Без фреймворков и сборки.** Нативные ES-модули, `el()` вместо JSX, CSS одним файлом. Открыл файл — видишь, что выполняется.
- **Канон неприкосновенен.** `fs/` — авторский контент, сайт его не меняет никогда (в Docker смонтирован `:ro`).
  Всё пользовательское живёт отдельно: общее — в `NOS_DATA/ufs`, личное — в браузере посетителя.
- **Два уровня «своего»:**
  - *локально* — VFS: посетитель двигает, удаляет, грузит файлы, создаёт черновики. Видит только он, сервер не знает;
  - *общее* — записи, папки `/ufs`, чат, форум: видят все, правила и лимиты — на сервере.
- **Приложения не знают про слои.** Любое приложение (включая игры в iframe) читает `/api/ls` и `/fs/...` — Service Worker и сервер сами сшивают канон, общее и личное.
- **Сервер не доверяет клиенту.** Клиент жмёт картинки и проверяет поля для удобства; сервер всё равно валидирует (размер, магия JPEG, размеры из заголовка, длины, частота).
- **Приватность по умолчанию.** Личка — P2P (WebRTC), текст через сервер не идёт. IP в модерации — солёный хэш. Внутреннее хранилище — в `.meta`, которое веб не отдаёт. Журнал IP не вечный: старое чистится само.
- **Свой origin — только своё.** На странице сайта выполняется лишь код из репозитория. Чужое (флешки, пользовательский DSP) либо берётся только из своей `fs`, либо запускается в песочнице без доступа к cookie и API. Встраивать сайт к себе может только автор (neocities).
- **Секреты не путешествуют.** Токены — в заголовках и в `.env`, никогда в адресе, логах или репозитории.
- **Безопасность — по-взрослому, но без паранойи.** Подробности, модель угроз и список недоделанного — в [security.md](security.md).
- **Дёшево и с потолками.** Каждое хранилище имеет лимит (на пользователя, на склад) и чистится по старшинству. Всё регулируется переменными окружения `NOS_*`.
- **Всё — параметр, всё — сигнал.** Любой регулятор любого окна, эффект окна, CSS-переменная ОС, ручка педали — цель, к которой можно протянуть провод. Источники сигналов (ручки, огибающие, LFO, ветер, курсор, громкость плеера, бочка из DAWN) живут в **шине ОС** (`core/bus.js`), а не в одном приложении: DAWN — лишь клиент шины. Новое приложение получает это бесплатно — достаточно обычных `<input type=range>`; хочешь больше — свой провайдер в `core/params.js`. Подробно — [signals.md](signals.md).
- **Каждое окно умеет описать себя командой.** Кнопка ⌘ в заголовке даёт строку, которая откроет такое же окно с такими же настройками там же (`w.cmd()` у приложения или по ключу окна). Из таких строк собираются скрипты `.nos`: один раз настроил — дальше одной кнопкой. Новое приложение с настройками — задай `w.cmd`.
- **Выбор из многого — грид.** Длинный перечень (цели проводов, пресеты синтов…) — не выпадающий список, а грид `ui/grid.js`: слева направо категории, вниз — квадратики, сверху поиск.
- **Тяжёлое считается дома.** Что можно посчитать заранее (глубина фото, 3D-сцены), считает тулчейн автора в `tools/` на его компьютере; результат — файлы рядом с исходником. Сервер досчитывает только недостающее и только в тихие часы, браузер — только своё (личный слой).
- **Кана — без обязательного Enter.** Учебная печать, свободная проверка, экзамен и переходы по карточкам должны работать автоматически, в том числе с незакреплённым вводом Mozc. Экзамен сдаёт любой завершённый набор каны после одинаковой паузы, не подсказывая длину или правильность. Кнопки остаются запасным способом; подтверждение клавишей Enter не должно быть условием прохождения. Мнемоника связывает смысл, образ, созвучие и звук (если уместно); не выдаём приблизительные созвучия за японское произношение.
- **Кана — постепенно убираем опоры.** В письме успех считается за целый глиф, без ошибок и раскрытия подсказок. После 5 чистых написаний убираем контур, после 25 самостоятельных — сам знак (остаётся произношение и азбука). Ошибки и раскрытие подсказок возвращают опоры; неоднозначные по звуку знаки и выключенный голос не переводим в слуховой режим. Статистика отдельно для каждого знака и азбуки, синхронизируется с аккаунтом.
- **Кана — точное написание и раздельная статистика.** Катакана ожидается с первого урока, встроенные кнопки あ / ア преобразуют текущий ввод без словаря Mozc и без Enter; Tab — дополнительный способ, если IME передаёт клавишу браузеру; после 8 секунд ожидания полностью верный по слогам ответ с хираганой вместо катаканы (в том числе смешанный) принимается; ошибки, лишние и пропущенные знаки не исправляются. Такие принятия учитываются отдельным счётчиком. Статистика учебной печати, проверки, перевода на экзамене и рукописного письма хранится отдельно, с разрезом азбук и общей историей. Старые счётчики сохраняются без выдуманного разбиения по режимам.
- **С юмором.** «Загрузчик» GTA VI, который не докачается, — тоже часть проекта (см. [apps.md](apps.md)).

## Сквозные механизмы

| Механизм | Где | Суть |
|---|---|---|
| Единый аккаунт | `chat.py: user_by_token` | HttpOnly-cookie `nos_chat` → `(uid, nick)`. Им пользуются записи, папки, комменты, форум, Джус |
| Регистрация = вход | `POST /api/chat/auth` | Нет ника — создаём, есть — входим. 1 регистрация с IP в 30 дней |
| Сшитая ФС | `server.py: api_ls / serve_fs` | `/fs` (главнее) + `/ufs` + виртуальные `.запись` в одном списке |
| Личный слой | `overlay-core.js` + `sw.js` + `core/vfs.js` | IndexedDB-оверлей поверх ответов сервера (см. [filesystem.md](filesystem.md)) |
| Инструмент сжатия картинок | `apps/post.js: shrink / pickImage` | canvas → JPEG с понижением качества до лимита. Параметры `dim`, `limit`: записи 256px, аватарки 256px, посты форума 800px |
| Проверка JPEG без декодирования | `posts.py: jpeg_dims / validate_jpeg`, `forum.py: check_jpeg` | магия `FFD8FF`, потолок байт, ширина/высота из SOF |
| Антиспам по частоте | `posts.py`, `chat.py`, `forum.py` | временные метки на `uid` в памяти/данных |
| Чистка текста | `clean_text` / `clean_md` | убираем управляющие, невидимые и bidi-символы |
| Безопасный вывод | клиент | чужой текст — только `textContent`; Markdown форума — сначала экранирование, потом разметка |
| Событие «поменялось» | `nos-posts-changed` | `{detail:{dir}}` — рабочий стол и проводники перечитывают папку |
| Атомарная запись на диск | все `save()` | пишем `*.tmp` → `os.replace` |
| Заголовки безопасности | `server.py: add_headers` | `frame-ancestors` (себе и neocities), CSP в режиме отчёта, COOP/COEP (нужно mGBA для SharedArrayBuffer), CORP, nosniff; `/tg.html` — без COOP/COEP. См. [security.md](security.md) |
| Фоновые задачи | `server.py: housekeeping` | раз в 30 с — `visits.json` на диск; раз в 6 ч — `Chat.cleanup` (истёкшие сессии, `ip_log` старше 180 дней) |
| Настройки посетителя | `core/util.js: store` | `localStorage` с JSON и try/catch |
| Шина сигналов | `core/bus.js`, `core/signals.js` | Источники (системная стойка + клиенты вроде DAWN) → провода → `Params`; тик 30 раз в секунду только пока есть провода |
| Команды окон | `core/cmd.js` | `w.cmd()` → строка; `Cmd.run(текст)` выполняет скрипт `.nos` |
| Грид выбора | `ui/grid.js` | `grid()` / `pickGrid()` / `gridButton()` — колонки-категории, квадратики, поиск |
| Файлы рядом | `core/types.js: isSidecar` | `<картинка>.depth.png`, `<картинка>.scene.nvx` — проводник группирует внизу, стол прячет |
| Настройки по умолчанию | `fs/etc/*.json` | `os.json` (обои), `gba.json` (эмулятор) — создаются один раз, дальше правятся руками |
