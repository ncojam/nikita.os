# Правила и соглашения по коду

## Общее

- Комментарии и тексты интерфейса — по-русски. Шапка каждого модуля объясняет, что он делает и какие у него правила.
- Без фреймворков и без шага сборки. Новые зависимости на клиенте — только вендорингом в `public/vendor/` с лицензией.
- Серверные зависимости — минимум (`requirements.txt`: aiohttp).

## Сервер

- Новый модуль — класс с хранилищем и `routes(app)`, подключается в `make_app()` **до** маршрута статики `/{tail:.*}`.
- Пользователь — только через `chat.user_by_token(request)`; свою авторизацию не изобретать.
- Пути из запроса — только через `resolve_inside()`. Служебные файлы — в `.meta/` (точка = не отдаётся).
- Всё, что пишет пользователь: чистка (`clean_text`/`clean_md`), потолок длины, лимит частоты, лимит количества, потолок склада.
- Картинки — проверка без декодирования (`jpeg_dims`); сервер никогда не перекодирует.
- Запись на диск — `tmp` + `os.replace`. Блокирующее (обход папок) — `asyncio.to_thread`.
- Лимиты — константы вверху модуля с переопределением через `NOS_*`.
- Ошибки для клиента — `{"error": "по-русски, понятно человеку"}` с осмысленным HTTP-кодом.

## Клиент

- DOM — через `el()`; чужой текст — `textContent`. `innerHTML` — только для своей разметки или после экранирования (`md()` форума).
- Окна — только `WM.open`; ресурсы приложения освобождать в `w.onClose`.
- Файлы читать через `/api/ls` и `/fs/...` (слои подмешаются сами); менять локально — только через `VFS`.
- Изменили общие записи/папки — `dispatchEvent(new CustomEvent("nos-posts-changed", {detail:{dir}}))`.
- Новый тип файла: `core/types.js` (`EXT`, `GLYPH`, `KIND_NAME`) + ветка в `openFile`.
- Новое приложение для ярлыков: экспорт `openX`, запись в `APPS` (`open.js`), при надобности кнопка в Пуске (`index.html` + `taskbar.js`).
- Картинки от пользователя — через `shrink`/`pickImage` из `post.js` с нужными `dim`/`limit`, не отдельной реализацией.
- Пути в `index.html` — абсолютные (страница открывается и с `/browser/...`).
- `localStorage` — через `store` (try/catch внутри).

## Имена, которые нельзя менять

- Расширение `.запись`, cookie `nos_chat`, ключи `store` (`desk.pos`, `wm.*`) — на них завязаны данные пользователей.
- Адреса псевдо-сайтов и их маршруты (`kursk.artists/...`) — на них ведут внешние ссылки.
- Эндпоинт `/api/entry` не переименовывать в `/api/stat` (блокировщики рекламы).
