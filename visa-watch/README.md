# Visa Watch

Домашний сторож страниц записи в BLS Spain (Москва). К сайту nikita.os отношения не имеет: сайт на VPS до BLS не достучался
(соединение режется на сетевом уровне), поэтому проверка живёт дома. Всё локально: свой интерфейс, свои данные, никаких токенов и ботов.

Раз в несколько минут (ночью и в начале часа чаще) открывает страницы записи и входа и ведёт журнал **изменений**:
«403, 403, 403…» — одна строка, пока не поменяется код ответа или заголовок. На каждое изменение сохраняет снимок:
скриншот, HTML и заголовки (в интерфейсе — кнопки «📷 Скриншот» и «📄 HTML»).

## Запуск на стационарном ПК (CachyOS, fish)

```fish
sudo pacman -S uv                      # если ещё нет
cd visa-watch
uv run visa_watch.py --install         # один раз: скачать Chromium (~150 МБ)
uv run visa_watch.py                   # сторож + интерфейс
```

Интерфейс: <http://127.0.0.1:8765>. Окно вкладки можно держать открытым: кнопка «🔔 Уведомлять» даст звук и уведомление,
когда страница перестанет отвечать 403.

`uv run visa_watch.py --once` — одна проверка с выводом в консоль, без интерфейса (удобно для первого теста).

## Только ваша сеть, без системного прокси

- переменные `http_proxy`, `https_proxy`, `all_proxy` и т. п. вычищаются из окружения при старте;
- простой режим работает с `trust_env=False`, Chromium запускается с `--no-proxy-server`;
- в интерфейсе показан **внешний IP**, каким вас видит интернет (запрос к api.ipify.org раз в полчаса; отключить: `ip_check = false`).
  Если там не ваш провайдерский адрес — трафик всё равно идёт через VPN/TUN на уровне системы, и приложение этого обойти не может:
  добавьте исключение для приложения (или адресов `blsspainrussia.ru`) в настройках вашего VPN.

## Режимы

| `mode` | Что делает | Когда брать |
|---|---|---|
| `browser` (по умолчанию) | настоящий Chromium (Playwright), честно загружает страницу, ничего не подделывает; скриншоты | ПК |
| `http` | простой запрос без браузера; скриншотов нет, JS-проверки не проходит | слабая плата |

## Расписание

Часовой пояс — `utc_offset` (Москва = 3), ночь — `night = "2-8"` (≈ 00–06 в Центральной Европе). Паузы `[до какой минуты часа, секунд]`:

| | минуты часа | пауза |
|---|---|---|
| ночь | 0–9 / 10–29 / 30–59 | 30 с / 60 с / 180 с |
| день | 0–4 / 5–59 | 60 с / 600 с |

К паузе добавляется случайные ±10 %; меньше 30 секунд нельзя.

## Конфиг (по желанию)

`~/.config/visa-watch/config.toml`. Всё из `DEFAULTS` в `visa_watch.py` можно переопределить, например:

```toml
mode = "http"
port = 8765
night = "3-7"
ip_check = true

[[targets]]
id = "doorstep"
name = "Запись"
url = "https://appointment.blsspainrussia.ru/Global/bls/doorstepservice"
```

## Автозапуск на ПК (systemd, пользовательский)

`~/.config/systemd/user/visa-watch.service`:

```ini
[Unit]
Description=Visa Watch

[Service]
WorkingDirectory=%h/путь/к/visa-watch
ExecStart=/usr/bin/uv run visa_watch.py
Restart=on-failure

[Install]
WantedBy=default.target
```

```fish
systemctl --user enable --now visa-watch
```

## Позже: Orange Pi Zero 2W

- Звёздочка про память: Chromium на 1–2 ГБ тяжёл. Если не тянет — `mode = "http"`, либо системный Chromium: `chromium_path = "/usr/bin/chromium"`.
- Чтобы открыть интерфейс с ПК: `host = "0.0.0.0"` и обязательно `token = "…"` (без токена приложение откажется стартовать),
  адрес вида `http://orangepi:8765/?token=…`.
- Данные лежат в `~/.local/share/visa-watch` (журнал `state.json`, снимки `snaps/`) — можно перенести папку.

## Что осталось на VPS

Старое слежение с сайта снесено, но его данные могут остаться в томе: `docker compose exec app rm -rf /data/visa /data/visa.json`.
