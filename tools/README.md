# tools — тулчейн автора

Всё, что тяжело считать на сервере, считается здесь — на своём компьютере. На сервер эта папка не едет (в Docker-образ копируются только `*.py` из корня и `public/`); результат — файлы, которые кладутся в `fs/` рядом с исходниками и копируются на сервер как обычно.

| Папка | Что |
|---|---|
| `photo3d/` | Фото → карта глубины (`.depth.png`) и воксельная 3D-сцена (`.scene.nvx`), режим для скриншотов Minecraft; «📦 Подготовить сайт» — модель и рантайм для глубины в браузере. См. [../docs/photo.md](../docs/photo.md) |

## Запуск

Нужен [uv](https://docs.astral.sh/uv/) (на CachyOS: `sudo pacman -S uv`). Зависимости uv ставит сам при первом запуске:

```fish
cd ~/Проекты/nikita-os
uv run tools/photo3d/toolchain.py        # откроется http://127.0.0.1:8770
```

В интерфейсе: слева — папка с картинками (по умолчанию `fs/` репозитория), выбрать картинки (Ctrl — несколько) → «🌊 Посчитать для выбранных» или «🧊 Сделать сцену» (Фото / ⛏ Minecraft). Справа — превью: фото, глубина, 3D.

Видеокарта AMD: обычный `onnxruntime` с PyPI считает на процессоре (Ryzen 5 5500 — пара секунд на картинку моделью base, этого хватает). Для ROCm/MIGraphX нужен пакет onnxruntime от AMD — тулчейн сам возьмёт видеокарту, если onnxruntime её видит (список устройств — в шапке интерфейса).
