# Open JTalk для Каны

Встроенный голос Mei работает в Web Worker / WebAssembly. Текст не отправляется внешнему TTS. Полный словарь 1.11, голос и браузерные файлы openjtalkjs 0.1.0 загружаются скриптом `python3 prepare_kana_tts.py` из корня проекта (автоматически в run.sh и deploy.sh). SHA-512/SHA-256 закреплены. Никаких npm install, Node или компиляции не требуется. Файлы не хранятся в Git. При недоступности источников сайт запускается, в Кане можно выбрать системный японский голос или отключить речь. Опубликованный worker 0.1.0 принимает dicUrl, поэтому архив проверяется и распаковывается в dictionary/ (все восемь файлов, без урезания словаря); также создаются gzip-копии для HTTP. Уже скачанный архив используется повторно. После успешной подготовки ресурсы лежат в public/vendor/openjtalk-v1; браузер загружает их только при воспроизведении. При обновлении ресурсов необходимо сменить версию пути и контрольные суммы.

Источники: @keanu-thakalath/openjtalkjs 0.1.0 (BSD-3-Clause), Open JTalk 1.11 (см. COPYING архива), Mei normal (Nagoya Institute of Technology / MMDAgent Project, CC BY 3.0). Контрольные суммы сверены с опубликованными значениями проекта nerosui/kokoro-js-jp; файлы и лицензии проверяются/копируются при подготовке. Синтезатор и голос не модифицируются.

Проверка в браузере: Кана → Печать → Open JTalk · Mei → Проверить голос. Затем начать урок, проверить прерывание фразы при вводе слога, повтор, отсутствие голоса во время проверочных карточек и остановку при закрытии окна. Для медленного первого соединения предусмотрен таймаут загрузки 120 секунд.
